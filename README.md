# Офис продаж «группа 33» — 360° тур

Интерактивный тур: три точки обзора (вход и второй свет, зал, подиум), переходы, план, зум, полный экран.
Панорамы — Corona Renderer, 8000×4000, в вебе уровни 2048/4096/8192.

Локальный просмотр: `python -m http.server 8000` в этой папке, затем http://localhost:8000/

Studio FR. Плеер: Marzipano (Apache 2.0, см. MARZIPANO_LICENSE.txt).
